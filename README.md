## About This Portfolio

I built this repository to document what I can actually do, rather than just
list it on a resume. Everything here was set up, broken, fixed, and written up
by me in my own lab environment.

My background is a mix of formal networking education and seven years of
hands-on technical work embedded in operations roles — supporting end users,
troubleshooting hardware and software, maintaining network infrastructure, and
writing the documentation other people relied on. This portfolio is where I
practice the parts of the job I could not get to in those roles.

## Projects

A virtualized Windows domain environment built from scratch: Windows Server
2022 domain controller running AD DS, DNS, and DHCP, with Windows 11 clients
joined to the domain. Covers user and group creation, organizational unit
structure, Group Policy, and shared drive permissions.

**Skills:** Active Directory · DNS · DHCP · Group Policy · Windows Server · Virtualization
